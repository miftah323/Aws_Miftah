Fase 1: Pengenalan Konsep VPS & Cloud
Penjelasan singkat perbedaan layanan hosting dan cloud:

Shared Hosting

Satu server fisik digunakan bersama-sama oleh banyak pengguna. Resource (CPU/RAM) dibagi rata dengan website lain.

Dedicated Server

Satu server fisik utuh yang disewa penuh oleh satu pengguna saja, tanpa perlu berbagi resource dengan pengguna lain.

Amazon Lightsail

Layanan VPS dari AWS yang simpel, praktis, dan ramah pemula dengan biaya bulanan yang terjangkau dan tetap.

Amazon EC2

Layanan cloud server dari AWS yang sangat fleksibel. Bebas dikustomisasi dan bisa ditingkatkan kapasitasnya sesuai kebutuhan besar.
